# React Profile Card

A simple React Profile Card built using React and Vite as part of my React Phase 1 learning.

## Features

- Functional Component
- JSX Expressions
- JavaScript Variables
- Conditional Rendering using Ternary Operator
- Local Image Import
- Modern React Setup with Vite

## Tech Stack

- React
- Vite
- CSS3

## Project Structure

```
react-profile-card/
├── public/
├── src/
│   ├── assets/
│   │   └── hero.png
│   ├── App.jsx
│   ├── App.css
│   ├── index.css
│   └── main.jsx
├── package.json
└── README.md
```

## Installation

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

Then open:

```
http://localhost:5173
```

- React Project Setup with Vite
- JSX Fundamentals

- Conditional Rendering using Ternary Operator
