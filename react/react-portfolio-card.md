# 🚀 React Profile Card

A simple Profile Card application built using **React + Vite** as part of my React learning journey.

This project focuses only on the **Phase 1 React Fundamentals** without using advanced React features like Props, State, Hooks, or Event Handling.

---

# 📸 Preview

A clean profile card displaying:

- 👤 Profile Name
- 💼 Role
- 📖 Learning Status

# ⚙ Installation

Clone the repository

```bash
git clone <repository-url>
```

Move into the project

```bash
cd react-profile-card
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

# 📄 Project Structure

## main.jsx

- Entry point of the application
- Creates the React Root
- Wraps App Component inside StrictMode
- Renders the App component

---

## App.jsx

Contains a simple Functional Component that displays:

- Name
- Role
- Learning Status

using JSX.

---

## App.css

Contains component specific styling.

---

## index.css

Contains global styles such as

- Margin Reset
- Padding Reset
- Box Sizing
- Background Color
- Font Family
